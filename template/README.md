# Family Ops starter workspace

All records in this folder are fictional examples. Copy the pattern into a separately controlled private workspace before using it with household information.

- Inbox: new information awaiting review
- Active: multi-step matters that require follow-up
- Ledger: Cases, Tasks, Deadlines and Reference
- HANDOFF.md: roles and operating notes
- AI_PROMPTS.md: optional, human-reviewed AI assistance

Workflow: receive information, record its origin, check for an existing related matter, decide on the next action, and verify completion. Preserve originals in private storage.
